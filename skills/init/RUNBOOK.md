# Shore Guard initialization runbook

1. Install the CLI globally: `npm install -g shore-guard`.
2. Alternatively, set up the CLI without a global install: `npx shore-guard setup`.
3. Log in from your terminal and never paste the key into chat: `shore-guard login`.
4. In Shore Sight, verify that this repository is connected.
5. Review the planned changes: `shore-guard init --plan --json`.
6. Find the default branch and strip `refs/remotes/origin/`, falling back to `main`: `git symbolic-ref refs/remotes/origin/HEAD`.
7. Optionally create and enter a setup branch: `git switch -c shore-guard/setup <default-branch>`.
8. Initialize the repository: `shore-guard init --json`.
9. Inspect changed paths: `git status --porcelain`.
10. Inspect the ignore changes: `git diff -- .gitignore`.
11. Inspect the complete configuration: `cat .shore/guard.json`.
12. Stage the generated files: `git add .shore/guard.json .gitignore`.
13. Commit the configuration: `git commit -m "chore: add Shore Guard configuration"`.
14. Follow the discovery skill and write its proposal to `.shore/proposals/<YYYY-MM-DD>-discovery.json`.
15. Review the proposal's modules, edges, rules, and tradeoffs; choose approve, modify, reject, or skip.
16. Approve it when ready: `shore-guard adopt --proposal <file> --approve --json`.
17. Inspect the adopted policy changes: `git status --porcelain && git diff -- .shore/policy.json .shore/policy.lock.json AGENTS.md`.
18. After approval, commit them: `git add .shore/policy.json .shore/policy.lock.json AGENTS.md && git commit -m "chore: adopt Shore Guard architecture policy"`.
19. Push the setup branch: `git push -u origin shore-guard/setup`.
20. Open the pull request: `gh pr create --base <default-branch> --title "Add Shore Guard configuration" --body "Adds Shore Guard configuration and an adopted architecture policy generated by /shore-guard:init."`.
21. Check the completed setup: `shore-guard doctor --json`.

To stay on the current branch, skip steps 7, 19, and 20. For CI, set `SHORE_API_KEY` in the CI secret store.
